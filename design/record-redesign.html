有余 · 记一笔改版原型（全功能）

吸收 A–H 全部 + 商家/标签/项目/拍照/模板/余额调整/多币种。核心结构：类型条 → 金额条（币种+拍照）→ 分类九宫格（彩色图标+子分类）→ 维度 chips（账户/账本/日期/记账人/商家/标签/项目）→ 备注 → 自绘计算器键盘（含运算、完成、保存再记）。带 需后端 的为需新增数据模型的能力。

A 键盘 自绘计算器：数字 + 运算(＋−) + 删除 + 完成 + 保存再记；金额显示在固定金额条。
B 图标 彩色圆形分类图标（与首页一致），选中带环，父类右下角标可展开子分类。
C 再记 保存后不退页、清空金额继续记。
D 日期「今天」chip 可改发生时间。
E/G 记账人 协作账本可「代谁记」（写入 created_by）。
F 备注 inline 备注。H 子分类 父类展开子类。
需后端 以下为新增数据模型：商家(merchant)、标签(tag,多对多)、项目(project)、票据图片(附件存储)、多币种(账户币种+交易币种+汇率+本位币)、模板(template)、余额调整(生成 adjust 类流水)。
建议落地分两批：第一批（不改或小改后端） A 键盘 / B 图标 / C 再记 / D 日期 / E 记账人 / H 子分类 / 借贷入口；第二批（后端扩展） 商家 / 标签 / 项目 / 票据 / 多币种 / 模板 / 余额调整。

交互：顶部实时预览「当前颜色 + 当前图标」；中部一排可选背景色；下部按场景分组切换，网格选图标。选中图标磁贴用所选实色背景 + 白色图标。

数据模型（落地）：分类表加 icon（图标 key，已有）与 icon_color（背景色 hex，新增，缺省品牌绿 #12a150）。渲染处（记账页/分类管理/流水/首页猜你要记等）统一：实色圆角磁贴 + 白色描边图标。

图标资产：本页所有图标即最终 SVG path，可整理进 utils/icons.js 的 ICON_PATHS，并按分组补充 ICON_GROUPS（供选择器分组展示）。iconDataUri 增加一个「实色背景 + 白色描边」变体用于彩色磁贴。

兼容：旧数据无 icon_color → 用默认色；旧 guessIcon 关键字映射保留，新增图标按 key 命中优先。

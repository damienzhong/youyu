① 头像颜色 = 用户可设置偏好

像主题一样从色板里挑（复用主题色板：绿/蓝/橙/紫/青/酒红/灰蓝/金）。后端存 users.avatar_color；账号页「个性化」出色板选择，选中样式与主题选择器一致（打勾 + 品牌绿环）。

② 记账人头像 = 各自颜色首字

家庭账本里成员支出条、每笔流水记账人、筛选 pill 都用「该成员颜色的首字圆 + 名字」，替换统一的 👤。颜色来自各自设置，天然区分；无性别角标、不花哨。

③ 性别（保留、低调）

作为独立中性字段：男 / 女 / 保密，纯展示不做功能门控。不参与头像配色，避免同性同色。

④ 数据来源

avatar_color / gender 随 /me 返回并可 POST /me 更新；listMembers 增补每人 avatarColor 用于染色。未设置则回退品牌绿。纯增量迁移 V42，不影响其它。

这版按现有风格、克制处理。方向 OK 我就落地：后端 V42（avatar_color + gender）、/me 与 /members 返回、账号页「个性化」色板 + 性别、明细页各成员彩色首字头像。

1. 身份数据条（新增）

hero 里加「记账天数 / 累计笔数 / 成长等级」——全部取自现有 /growth 概览，只读、不可点，给账号"分量"，不与「我的」的成长入口冲突。

2. 会员卡（新增）

把套餐从一行灰字升级为一张卡：套餐名 + 有效期 + 一句权益（干净无广告 · 数据可导出）。「了解权益」为可选入口，无付费墙时可只做说明页。

3. 账号信息（新增）

用户 ID（可复制，反馈客服用，取自 /me.id）+ 加入时长。都是账号本身的信息，别处没有。

5. 刻意不加的

数据导出 / 账单导入 / 回收站 / 主题 / 提醒 / 邀请（已在「我的」）；用户协议 / 隐私政策（按你的意见移除）。账号页不重复、不堆合规入口。

6. 数据来源都真实

ID / plan / 有效期来自 /me，天数 / 笔数 / 等级来自 /growth；不新造后端字段（「加入时长」如无注册时间，可用会员起始 planStartedAt 近似或先不显示）。

这版"适度增信息"的方向你觉得如何？确认后我落地到 pages/account/account.vue。如果你觉得会员卡 / 用户ID 某项没必要，或还想加别的账号级信息（比如登录设备、消息通知开关），也可以现在定。
